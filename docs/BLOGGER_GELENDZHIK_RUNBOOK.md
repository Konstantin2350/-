## Шаг 3. Подключить входящие сообщения — сегодня или завтра

### Через Wazzup

1. В Wazzup подключить Instagram-аккаунт блогера `valera_posmotrela`.
2. Оставить подключёнными WhatsApp и Telegram Personal `@Konstantin2350`.
3. В защищённых переменных сервера указать:

```dotenv
WAZZUP_API_KEY=значение_из_кабинета
WAZZUP_WEBHOOK_TOKEN=отдельная_случайная_строка
WAZZUP_AUTO_REPLY=false
```

Ключи нельзя отправлять в чат или записывать в Git. После пробной входящей заявки
включить `WAZZUP_AUTO_REPLY=true`.

4. После выкладки вызвать от имени менеджера:

```text
POST /v1/integrations/wazzup/subscribe/gelendzhik-blogger-2708
```

Оркестр зарегистрирует callback Wazzup
`/v1/webhooks/wazzup/gelendzhik-blogger-2708`, примет входящее сообщение,
создаст лид, передаст его человеку и подготовит ответ. После безопасного теста
Оркестр сможет отправлять уточняющий вопрос в исходный Instagram-диалог через
Wazzup.

### Без Wazzup

1. Подключить номер к WhatsApp Business API.
2. Указать callback:
   `/v1/webhooks/leads/gelendzhik-blogger-2708`.
3. Передавать `x-webhook-secret` и стабильный `external_id` диалога.
4. Преобразовать входящее событие провайдера в формат:

```json
{
  "external_id": "wa-dialog-123",
  "channel": "whatsapp",
  "message": "Валера. Нужна квартира с 3 по 10 сентября",
  "name": "Анна",
  "phone": "+79990000000",
  "answers": {
    "stay_dates": "3–10 сентября",
    "guests": "2 взрослых и 1 ребёнок"
  }
}
```

Если Business API ещё нет, оператор вносит сообщение этим же запросом вручную.

## Шаг 5. Ответственный человек — до теста

Назначить одного основного и одного резервного ответственного. Основной человек:

- забирает заявку из `/v1/operator/handoffs`;
- отвечает не позднее 5 минут;
- фиксирует статус через `PATCH /v1/leads/{lead_id}`;
- переводит лид в `contacted`, `won` (бронь подтверждена) или `lost`.
